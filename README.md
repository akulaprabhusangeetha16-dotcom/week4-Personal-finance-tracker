# Personal Finance Tracker

## 📌 Project Overview
The Personal Finance Tracker is a Python-based command-line application that helps users record, manage, and analyze personal expenses.  
It is designed to demonstrate Python file handling, modular programming, and object-oriented concepts through a real-world use case.

---

## 🎯 Objectives
- To record daily expenses
- To categorize expenses for better tracking
- To store expense data persistently using files
- To generate basic expense reports
- To practice modular and structured Python programming

---

## 🛠️ Technologies Used
- Python 3
- JSON for data storage
- Command Line Interface (CLI)
